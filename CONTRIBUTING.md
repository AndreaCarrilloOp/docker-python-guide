# Contributing

Use `main` as the learning entry point. Create a short-lived feature branch only when developing a change. Do not create branches for individual tutorial modules.

- Keep every example runnable from its own directory.
- Preserve earlier checkpoints when introducing new concepts.
- Use Python 3.11 and Docker Compose v2.
- Add functional tests for behavior changes.
- Keep credentials outside Git; use empty `.env.example` templates.
- Run the example's tests and container health check before opening a pull request.

All contributions are covered by the repository's MIT license.
